# 二自由度平面SCARA型ロボットアームのランダム目標追従シミュレーション（ver8.5）

Google Colab（T4環境等）のヘッドレス環境で動作する、2自由度平面スカラ（SCARA）型ロボットアームの目標追従（ポインティング）シミュレータです。

## 概要 (ver8.5)
本プロジェクトでは、物理エンジン「PyBullet」を用いて長アーム（合計1.7m）の挙動をシミュレートし、4秒ごとにランダムな位置にワープする目標物（赤い球体）をアーム手先が追従する様子を自動でMP4動画およびCSVスコアファイルに出力します。
現実のセンサーブレを模した「観測ノイズ（5cmのガウスノイズ）」入力を受けた際の、アームの追従エラーを統計的に評価する仕様を搭載しています。

### システムの定義
- **状態 (State)**: エンドエフェクタの現在位置座標、およびノイズが混入した目標位置の座標
- **アクション (Action)**: 各関節（Joint 1: 青、Joint 2: 緑）の目標角度
- **推論ポリシー**: 余弦定理を用いた直接解析解法（Analytical IK）

## 特徴と工夫点
- **シンギュラリティとカメラバグの完全克服**: 数値IK関数のロック現象を数式（余弦定理）による直接代数解法へ完全置換。また、ソフトウェアレンダラーの画角計算の無限発散バグを、アスペクト比の固定パッチによって完全解決し、美しい俯瞰映像の出力を実現しました。
- **統計処理のリアルタイム統合**: 直近15回分のターゲットに対する最小到達距離（スコア）の「平均値」と「分散」をリアルタイムで算出・描画します。

## 今後の展望 (継続プロジェクト)
決定論的な数式解法では観測ノイズをそのまま拾ってアームがガタつく限界があるため、今後はノイズレスなデータで事前学習させた「ニューラルネットワーク（NN）近似学習ポリシー」を導入し、AIの統計的平滑化能力によるノイズ吸収・ロバスト制御の実現を目指します。

## 動作環境

- PyBullet
- OpenCV (cv2)
